# First-Issue-Finder
A web application to help beginners discover beginner-friendly GitHub issues.
First Issue Finder

About the Project

First Issue Finder is a web application designed to help beginners discover beginner-friendly issues on GitHub. It helps new contributors explore open-source projects and find issues that match their interests and skills.

Features

- Search GitHub issues using keywords.
- Filter issues by programming language and labels.
- Explore issue details and repository information.
- View a suitability score with an explanation.
- Save interesting issues for later.
- Track contribution progress.
- Switch between dark and light themes.
- Follow a checklist before starting an open-source contribution.

Technologies Used

- HTML
- CSS
- JavaScript
- GitHub REST API
- Browser Local Storage

How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser, or use the VS Code Live Server extension.
4. Start exploring GitHub issues.
